# NCM 转 MP3 · 本地转换器

[English](README_EN.md)

纯浏览器本地运行的音频工具：**NCM 解密转换** + **去人声提取伴奏**。零依赖、零上传，文件全程不离开你的设备。

## 功能

- 🎵 **NCM 转 MP3/FLAC/OGG**：拖拽或选择 `.ncm` 文件，批量转换，自动识别输出格式
- 🏷️ **元数据保留**：自动提取歌名、歌手、专辑、封面，按「歌手 - 歌名」命名
- 🎤 **去人声提取伴奏**：中置声道消除 + 四阶 Butterworth 低频保留（保住底鼓/贝斯），输出无损 WAV
- 📦 **批量打包**：转换结果一键打包 ZIP 下载
- 🔒 **完全本地**：AES 解密与音频处理均在浏览器内完成，无任何网络请求

## 使用

这是一个纯静态站点，任何静态服务器都能跑：

```bash
npm run dev        # 本地预览，默认 http://localhost:7100/
```

或直接部署到 GitHub Pages / Vercel / Nginx——把仓库根目录作为静态目录即可，无需构建。

## 原理

- **NCM 解密**：AES-128-ECB（浏览器 WebCrypto 不支持 ECB，内置纯 JS 实现，S 盒按 GF(2⁸) 数学定义生成）解出流密钥与元数据，再做密钥盒流解密还原音频
- **去人声**：主流歌曲人声混合在立体声正中央，衰减左右声道的共同成分即可消除；200Hz 以下低频经四阶 Butterworth 低通保留，避免底鼓、贝斯被一并消除
- **局限性**：去人声对人声居中的流行歌效果最好；现场版、人声大偏移或单声道曲目效果有限
